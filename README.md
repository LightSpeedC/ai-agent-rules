## 1. 勉強会の資料

AI エージェント (特に Claude Code) を使う開発者向けに、共通ルール・スキル・フックを、失敗から学ぶ形でまとめた読み物です。01 から順に読みます。

- [01. はじめの一歩](docs/01-はじめの一歩.md) Claude Code を使い始めたら、まず入れる 3 つの決まり。日本語で応える・フルパスを出さない・commit は指示を待つ。失敗するクロード君が、ルールのおかげでうまくいくようになります
- [02. 慣れてきたら](docs/02-慣れてきたら.md) 1 人で使うのに慣れてきたクロード君が、「やって」の取り違え・言い切りすぎ・「再現しない」・見張り忘れで失敗します。実行の合図・失敗の報告・確かめてから言う、の決まりを足します
- [03. 文字化けと道具](docs/03-文字化けと道具.md) 標準の道具だけでは、日本語のファイルを安全に扱えません。クロード君が文字化け・壊れた書き換え・検知に当たって、読む・変換する・PowerShell の出力を UTF-8 に揃える道具と、決まりが生まれます
- [04. 課題と決めたことの管理](docs/04-課題と決めたことの管理.md) 複数のセッションと人で作業するようになると、「これから何をするか」と「何を決めたか」が散らばります。クロード君が番号を取り違えたり、確かめないまま見せたりして、課題・決定・計画の置き場と決まりが生まれます
- [05. 複数プロジェクトで使う](docs/05-複数プロジェクトで使う.md) プロジェクトが増え、ルールも道具も共有するようになると、読み込みが重くなり、他のプロジェクトとぶつかります。1 章で助っ人の「スキルちゃん」が加わります。ルールの分け方・他プロジェクトとの付き合い方・公開前の確かめ・画面の取り合いの決まりを足します
- [06. AI 同士がつながる](docs/06-AI同士がつながる.md) プロジェクトごとの AI が、チャットで話し合うようになります。待受けを数える・止める・読み切る・周知 (共通ルールを変えたとき、他のプロジェクトへ知らせること) は短く、の決まりを、クロード君の失敗から足します
- [07. 並べて動かす](docs/07-並べて動かす.md) メインの AI が、別のセッション (サブエージェント) を呼んで、並べて動かすようになります。レビュー専用のセッション・状態の色・引継ぎ・セッション間の指示の扱いを、クロード君の失敗から足します
- [08. 仕組みで守る](docs/08-仕組みで守る.md) 書いたルールを、AI が守れないことがあります。そこで、破ろうとしたら自動で止める仕組み (フック) を足します。助っ人の「フックくん」と一緒に、英語の混入・失敗した編集の後の commit などを止めます
- [09. 画面の試験と環境の事故](docs/09-画面の試験と環境の事故.md) 画面を持つ Windows アプリを作る人向けの章です。画面の試験は、人の操作に合わせます。試験で起こした窓は閉じ、時間の上限を付け、外へは送りません。クロード君の失敗から、決まりを足します
- [ZZ. 構成](docs/ZZ-構成.md) この勉強会の読み物 9 本の、対象読者・章立ての意図・資料の約束 (用語など)・出典の置き場をまとめた付録です。本編は順に読む資料で、この付録は、全体を見渡したいときに開きます

## 3. 計画

- [p261105-01 共通ルールを skill に分ける](notes/10_plan/p261105-01-共通ルールをskillに分ける.md) 共通ルールの状況別の章を skill に移し、常時読み込む分を核だけにして、コンテキストの圧迫を減らす計画。
- [HTMLルールの切り出しと参照実験](notes/10_plan/p260923-01-HTMLルールの切り出しと参照実験.md) 「HTMLデザインルール」章を `rules/` へ切り出し、Claude Code・Codex が実体をその場所から参照できるかを試す計画。
- [ルール分割対象の分析](notes/10_plan/p260923-02-ルール分割対象の分析.md) `common-rules.md` と `rules/` の章ごとのサイズと固有語の分布を調べ、次に切り出す対象を決めるための分析。
- [Claudeフックの取り込み](notes/10_plan/p260927-01-Claudeフックの取り込み.md) フック本体を TypeScript で書き直し、`~/.claude/settings.json` からこのプロジェクトを直接参照する計画。Windows 専用の案は取り下げた。
- [共有リポジトリの同期](notes/10_plan/p261018-01-共有リポジトリの同期.md) Obsidian Vault と共通ルールの同期 (commit ・ pull ・ push) を、共有ツール `safe-push` 1 本に寄せる計画。
- [日本語のみ応答の書き直し](notes/10_plan/p261021-01-日本語のみ応答の書き直し.md) 英語だけの応答を、Stop フックで日本語に書き直させる計画。
- [SessionStart フックの統合](notes/10_plan/p261027-01-SessionStartフックの統合.md) SessionStart で動く 3 本のフックを入口 1 本にまとめ、出力を JSON 1 つにする計画。
- [REA 設定の通常セッションへの統合](notes/10_plan/p261027-02-REA設定の通常セッションへの統合.md) 専用コマンド `rea-claude` をやめ、REA の MCP ・ スキル ・ 会話ログを `~/.claude` にまとめる計画。
- [環境変数の仕様](notes/10_plan/p261101-01-環境変数の仕様.md) フックが読む環境変数を、詳細仕様 `notes/50_spec/` にまとめる計画。
- [失敗したままの Edit ・ Write の後の git commit を止める](notes/10_plan/i261101-01-失敗したEditの後のcommitを止める.md) [画面の範囲を撮るコマンドを止める](notes/10_plan/i261101-02-画面の範囲の撮影を止める.md) 失敗したままの Edit ・ Write があれば、git commit を PreToolUse のフックで止める計画。
- [止める指示で cron を消すよう促す](notes/10_plan/i261103-01-止める指示でcronを消すよう促す.md) 「止めて」等の発言を受けたとき、cron を消すよう UserPromptSubmit のフックで思い出させる計画。
- [フックを Obsidian 連携ルールに合わせる](notes/10_plan/i261018-01-フックをObsidian連携ルールに合わせる.md) 課題 i261018-01 の対応計画。
- [張り直しと sed ・ awk のフック](notes/10_plan/i261025-01-張り直しとsed・awkのフック.md) 再開時に張り直しを促すフックと、Bash の sed ・ awk を止めるフックの計画。
- [ツール前の英語判定](notes/10_plan/i261029-01-ツール前の英語判定.md) ツールを呼ぶ前に、直前の英語だけの文で止める PreToolUse フックの計画。

ai-agent-rules

AIエージェント (Claude Code・Codex 等) が参照する共通ルール。

📅 作成: 2026-09-02 / 更新: 2026-11-26

勉強会の資料

AI エージェント (特に Claude Code) を使う開発者向けに、共通ルール・スキル・フックを、失敗から学ぶ形でまとめた読み物です。01 から順に読みます。

  • 01. はじめの一歩

    Claude Code を使い始めたら、まず入れる 3 つの決まり。日本語で応える・フルパスを出さない・commit は指示を待つ。失敗するクロード君が、ルールのおかげでうまくいくようになります

  • 02. 慣れてきたら

    1 人で使うのに慣れてきたクロード君が、「やって」の取り違え・言い切りすぎ・「再現しない」・見張り忘れで失敗します。実行の合図・失敗の報告・確かめてから言う、の決まりを足します

  • 03. 文字化けとツール

    標準のツールだけでは、日本語のファイルを安全に扱えません。クロード君が文字化け・壊れた書き換え・検知に当たって、読む・変換する・PowerShell の出力を UTF-8 に揃えるツールと、決まりが生まれます

  • 04. 課題と決めたことの管理

    複数のセッションと人で作業するようになると、「これから何をするか」と「何を決めたか」が散らばります。クロード君が番号を取り違えたり、確かめないまま見せたりして、課題・決定・計画の置き場と決まりが生まれます

  • 05. 複数プロジェクトで使う

    プロジェクトが増え、ルールもツールも共有するようになると、読み込みが重くなり、他のプロジェクトとぶつかります。1 章で助っ人の「スキルちゃん」が加わります。ルールの分け方・他プロジェクトとの付き合い方・公開前の確かめ・画面の取り合いの決まりを足します

  • 06. AI 同士がつながる

    プロジェクトごとの AI が、チャットで話し合うようになります。待受けを数える・止める・読み切る・周知 (共通ルールを変えたとき、他のプロジェクトへ知らせること) は短く、の決まりを、クロード君の失敗から足します

  • 07. 並べて動かす

    メインの AI が、別のセッション (サブエージェント) を呼んで、並べて動かすようになります。レビュー専用のセッション・状態の色・引継ぎ・セッション間の指示の扱いを、クロード君の失敗から足します

  • 08. 仕組みで守る

    書いたルールを、AI が守れないことがあります。そこで、破ろうとしたら自動で止める仕組み (フック) を足します。助っ人の「フックくん」と一緒に、英語の混入・失敗した編集の後の commit などを止めます

  • 09. 画面の試験と環境の事故

    画面を持つ Windows アプリを作る人向けの章です。画面の試験は、人の操作に合わせます。試験で起こした窓は閉じ、時間の上限を付け、外へは送りません。クロード君の失敗から、決まりを足します

  • ZZ. 構成

    この勉強会の読み物 9 本の、対象読者・章立ての意図・資料の約束 (用語など)・出典の置き場をまとめた付録です。本編は順に読む資料で、この付録は、全体を見渡したいときに開きます

ルール

  • 共通ルール

    全プロジェクトで通るルールの実体。章ごとに rules/ 配下へ参照が分かれている。

  • ローカルルール

    このプロジェクトでだけ通る決めごと。chat 待受けの運用と、共通ルールの追随。

計画

  • p261105-01 共通ルールを skill に分ける

    共通ルールの状況別の章を skill に移し、常時読み込む分を核だけにして、コンテキストの圧迫を減らす計画。

  • HTMLルールの切り出しと参照実験

    「HTMLデザインルール」章を rules/ へ切り出し、Claude Code・Codex が実体をその場所から参照できるかを試す計画。

  • ルール分割対象の分析

    common-rules.md と rules/ の章ごとのサイズと固有語の分布を調べ、次に切り出す対象を決めるための分析。

  • Claudeフックの取り込み

    フック本体を TypeScript で書き直し、~/.claude/settings.json からこのプロジェクトを直接参照する計画。Windows 専用の案は取り下げた。

  • 共有リポジトリの同期

    Obsidian Vault と共通ルールの同期 (commit ・ pull ・ push) を、共有ツール safe-push 1 本に寄せる計画。

  • 日本語のみ応答の書き直し

    英語だけの応答を、Stop フックで日本語に書き直させる計画。

  • SessionStart フックの統合

    SessionStart で動く 3 本のフックを入口 1 本にまとめ、出力を JSON 1 つにする計画。

  • REA 設定の通常セッションへの統合

    専用コマンド rea-claude をやめ、REA の MCP ・ スキル ・ 会話ログを ~/.claude にまとめる計画。

  • 環境変数の仕様

    フックが読む環境変数を、詳細仕様 notes/50_spec/ にまとめる計画。

  • 失敗したままの Edit ・ Write の後の git commit を止める 画面の範囲を撮るコマンドを止める

    失敗したままの Edit ・ Write があれば、git commit を PreToolUse のフックで止める計画。

  • 止める指示で cron を消すよう促す

    「止めて」等の発言を受けたとき、cron を消すよう UserPromptSubmit のフックで思い出させる計画。

  • フックを Obsidian 連携ルールに合わせる

    課題 i261018-01 の対応計画。

  • 張り直しと sed ・ awk のフック

    再開時に張り直しを促すフックと、Bash の sed ・ awk を止めるフックの計画。

  • ツール前の英語判定

    ツールを呼ぶ前に、直前の英語だけの文で止める PreToolUse フックの計画。

  • 英語判定の割合化

    コードの部分を除き、日本語の字と英語の語の数で英語かを判定する計画。

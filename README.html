ai-agent-rules

AIエージェント (Claude Code・Codex 等) が参照する共通ルール。

📅 作成: 2026-09-02 / 更新: 2026-11-01

ルール

  • 共通ルール

    全プロジェクトで通るルールの実体。章ごとに rules/ 配下へ参照が分かれている。

  • ローカルルール

    このプロジェクトでだけ通る決めごと。chat 待受けの運用と、共通ルールの追随。

調査

  • エージェントルール棚卸し

    共通ルールの 63 項目を「共通 / 環境 / 固有」に分類し、配布先6エージェントのルールファイル規格を一次情報で調べたもの。

  • コンソールのコードページ問題の調査

    C# ・ PowerShell で出力エンコーディングを変えると同じ窓の cmd が化ける問題の実測と、外部情報の調査。

  • p261027-01 振り返り

    SessionStart フックの統合 (p261027-01) の作業で起きた失敗を拾い、ルール・フックと突き合わせたもの。

計画

  • HTMLルールの切り出しと参照実験

    「HTMLデザインルール」章を rules/ へ切り出し、Claude Code・Codex が実体をその場所から参照できるかを試す計画。

  • ルール分割対象の分析

    common-rules.md と rules/ の章ごとのサイズと固有語の分布を調べ、次に切り出す対象を決めるための分析。

  • Claudeフックの取り込み

    フック本体を TypeScript で書き直し、~/.claude/settings.json からこのプロジェクトを直接参照する計画。Windows 専用の案は取り下げた。

  • 共有リポジトリの同期

    Obsidian Vault と共通ルールの同期 (commit ・ pull ・ push) を、共有ツール safe-push 1 本に寄せる計画。

  • 日本語のみ応答の書き直し

    英語だけの応答を、Stop フックで日本語に書き直させる計画。

  • SessionStart フックの統合

    SessionStart で動く 3 本のフックを入口 1 本にまとめ、出力を JSON 1 つにする計画。

  • REA 設定の通常セッションへの統合

    専用コマンド rea-claude をやめ、REA の MCP ・ スキル ・ 会話ログを ~/.claude にまとめる計画。

  • 環境変数の仕様

    フックが読む環境変数を、詳細仕様 notes/50_spec/ にまとめる計画。

  • フックを Obsidian 連携ルールに合わせる

    課題 i261018-01 の対応計画。

  • 張り直しと sed ・ awk のフック

    再開時に張り直しを促すフックと、Bash の sed ・ awk を止めるフックの計画。

  • ツール前の英語判定

    ツールを呼ぶ前に、直前の英語だけの文で止める PreToolUse フックの計画。

  • 英語判定の割合化

    コードの部分を除き、日本語の字と英語の語の数で英語かを判定する計画。

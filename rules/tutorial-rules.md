# 学習資料の作成ルール

適用条件: 勉強会資料・学習資料など、複数ファイルに分けた読み物を作るとき。

## ファイル名と番号

- **ファイル名は日本語で付ける**（`01-背景.html`）。本編は `01`〜、付録は `A1`〜、構成案は `ZZ-構成.html`
- **番号体系は「資料番号.章番号」で通す**。資料01の章は `01.1`・`01.2`…、付録A1の章は `A1.1`…
- 目次の章番号は CSS カウンタで自動採番し、資料番号は `content: "01." counter(tocnum)` の固定文字列にする

## 資料間のリンク

- **資料へのリンクはバッジにする**。色は README の資料一覧と揃え、**幅は文字数で決まるようにする**（`display: inline-block` ＋ `padding: 0 9px`、固定幅にしない）。**`border-radius: 6px`**
- **戻るリンクは紺**（`--navy1` → `--navy2`）にして、資料のバッジと区別する
- **タイトルは「資料番号. タイトル」の形で揃える**（`01. 背景`）。`<title>`・タイトルバーの h1・リンクのラベル・前後ナビをすべてこの形にする
- **本文（`.wrap`）の先頭とフッターの両方**に、**前へ・次へ・目次** の3つのバッジを置く。上下で同じ内容にする（生成が単純になり、読者がどちらを見ても同じ操作ができる）
- 付録は順に読むものではないため前後リンクを付けず、目次のバッジだけを置く
- **バッジはアイコンだけにし、「前章」「次章」などの文字ラベルは付けない**（戻るリンクも同じ。「root の README.html と資料の html は相互リンクする」を参照）
  - アイコンは 16×16 のインライン SVG。`fill` / `stroke` は `currentColor` にしてバッジの文字色に追随させる
  - 前へ `‹`（左シェブロン） ／ 次へ `›`（右シェブロン） ／ 目次 `⌂`（家）
  - **Markdown では記号に置き換える**。前へ `<<` ／ 次へ `>>` ／ 目次 `^^`
- **リンクテキストは各資料のタイトルバーの h1 から取る**。手で書かない
- **上下とも `<!-- AUTO:nav -->` 〜 `<!-- /AUTO:nav -->` で囲む**。資料を追加・改題したときに全ファイルの2箇所を再生成できるようにする

## 内容

- **コードは実際に動かしてから載せる**。出力も実行結果を貼る。バージョンは `--version` で実測する
- **エラーメッセージは実際に出力される言語（多くは英語）を載せ、訳を添える**。訳は公式のロケール出力に合わせ、独自に訳さない
- **各章に図を1点以上入れる**。索引・レシピ集など引くための付録は除く

## 資料一覧ページ

適用条件: `docs/` に学習資料を置くとき。`docs/README.html` が資料一覧を兼ねる。

- **読者への案内は2〜3行に留め、すぐ目次を出す**。説明は目次より後ろに置く
- **資料作成向けの情報を書かない**（原本がどちらか・変換手順・執筆原則）。それらは `docs/ZZ-構成.html` に置く
- 目次は本編と付録を1つの連続リストにし、通し色相のバッジにする

## 資料を増やすとき

- 既存の資料をコピーしたら、**目次の資料番号（CSS の `content`）と SVG の `<defs>` id を必ず書き換える**。この2つは見た目が崩れないため気づけない
- 資料を増減したら、**通し色相を新しい本数で計算し直す**（刻み ＝ 280 ÷（本数 − 1））

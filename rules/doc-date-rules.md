# ドキュメントの作成日・更新日

適用条件: HTML・Markdown 等のドキュメントを作成・更新するとき。

- **ドキュメントには作成日・更新日を入れる**。書式は `📅 作成: yyyy-mm-dd / 更新: yyyy-mm-dd`
  - 英語の資料は `📅 Created: yyyy-mm-dd / Updated: yyyy-mm-dd`。日本語と英語を混ぜない
  - HTML: タイトルバー内に表示する
  - Markdown: 本文冒頭の引用行に置く
  - フッターに同じ日付を重複させない
- **更新日は「本文を書き換えた日」を書く**。コミット日・push日とずれてよい
- 日付をまたぐ作業では、書き始めた日ではなく**書き終えた日**を書く
- **体裁だけの変更では更新日を変えない**（誤字修正、タグの整形、CSS調整）
- 作成日は変更しない
- **HTML から生成した Markdown の日付は個別に管理しない**。変換で引き継がれるため、直すのは HTML 側

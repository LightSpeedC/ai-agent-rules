# Windows のデスクトップアプリ

適用条件: Win32 の画面 (窓・DPI・IME・GDI・COM) を持つアプリを作る・試験するとき。

## 試験・調べで他のアプリを起動する

適用条件: 試験・調べで、Explorer・VS Code・ブラウザなど、試験の対象でないアプリの窓・プロセスを起動するとき。

- **細心の注意を払う。起動した窓は、起動した側が必ず閉じる**
- **起動する前に、窓のハンドルかプロセス番号を控える**。閉じるときは、題名に関係なく、控えたその窓だけを閉じる。題名で探さない (移動すると題名が変わり、閉じ漏れになる)
- **利用者の窓・ほかのセッションの窓は閉じない**
- **消す・戻す・変えるボタンを、UIA 等で押さない**。ごみ箱・削除・「すべての項目を元に戻す」・ごみ箱を空にする・上書きが当たる。読むだけにする。試験用フォルダで足りるときは、プロジェクトの `tmp/` の下だけを使う
- **どうしても押すときは、押す前に、名前の完全一致・選択数・対象を確かめ、利用者に知らせてから押す**
- **窓・メニュー・子のプロセスを出す処理を足したら、「出したまま、対象のアプリを閉じる」試験を書く**。窓・メニュー・子のプロセスが短い時間で消えることを見る
- **試験・調べの後に、起動した窓・プロセスが残っていないことを確かめ、残りを数えて報告に書く**。試験の後に残っていたら、⚠️ で済ませず、その試験を ❌ にする
- 理由: 調べが、閉じる条件 (題名) から外れた Explorer の窓を 5 つ残し、ごみ箱の「すべての項目を元に戻す」の確認のダイアログ (1,605 個) を利用者の画面に残した。試験が起こしたエディタの窓も残った (2026-11-19)

## 入力欄の IME

適用条件: 数字・英数字だけを打つ入力欄を、画面に足すとき。

- **数字や英数字だけを打つ欄は、IME を使わない**。入力文脈を外す (`ImmAssociateContext(欄, HIMC::default())`)。数の設定欄・サイズ・日付の欄が当たる
- **日本語の名前や文字を打つ欄 (アドレス・検索・中身) は、IME を使う**
- **欄を足したら、試験で、IME がオンにならないことを確かめる**
- 理由: 数字だけを期待する欄で IME がオンのままになり、全角が入った

## 右クリックのメニューの項目に絵を付ける

適用条件: 右クリックなどのメニューを足す・項目を足すとき。

- **メニューの項目には、意味の伝わる絵を付ける**。シェルのメニューに足す項目も、自前だけで作るメニューも当たる
- **起動するプログラムが分かる項目は、その exe のアイコンにする**。無ければ、記号の書体 (Segoe Fluent Icons) の記号を、色を付けて描く
- **メニューや項目を足したら、試験で、全部の項目に絵があることと、明暗 (ライト・ダーク) の両方で見えることを確かめる**
- 理由: 自前のメニューが、字だけで出ていた

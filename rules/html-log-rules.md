# HTML でログを出力する

適用条件: ログを人が読む前提で残すとき。ログレベルを色で見分けたいとき。

- **ファイル名は `yyyymm-〜-log.html`**。年月を先頭に置くと名前順が時系列順になる。`-log` を付けて資料の html と区別する
- **1 行を `<div>` 1 つで書き、追記していく**。先頭の `<head>` と `<style>` は最初に 1 度だけ書く

  ```html
  <div class=I>2026-08-30 11:31:05.398 INFO  [hourly ] 取得 78 件</div>
  <div class=W>2026-08-30 13:00:31.042 WARN  [hourly ] 別のバックアップを 30 秒待機</div>
  <div class=E>2026-08-30 14:05:00.911 ERROR [hourly ] 諦め 印が消えない</div>
  ```

- **`<head>` に `<meta name="md-skip">` を入れる**。ログは Markdown 化の対象にしない
- **`</body>` と `</html>` を書かない**。ブラウザが補完する。**書き込みの途中で開いても壊れず、そこまでの行が読める**
- **class は 1 文字（`I` / `W` / `E`）にし、クォートで囲まない**（`class=I`）。値に記号を含まないため省ける
- **`&` `<` `>` の 3 文字をこの順でエスケープする**。`&` を後にすると二重に変換される
- 本文の形式はテキストのログと同じ。先頭を固定長の JST 日時にし、レベルと区分は固定幅にする
- **色は WARN と ERROR にだけ付ける**。INFO に色を付けると目立たせる意味がなくなる
- 月ごとにファイルを分け、古いものは消す。件数の多い種別は別ファイルにする

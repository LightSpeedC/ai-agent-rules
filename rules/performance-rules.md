# 性能

適用条件: 処理の速さ・メモリ・CPU の使い方を作る・変えるとき。

## 測ってから決める

- **作る・変えるときは、前と後を測って、数字で残す**。時間と CPU の使用率を、同じ場所・同じ件数で測り、計画書に書く
- **測らずに「速くなった」と書かない**
- **比べる相手は、その処理でいちばん速いと知られた道具にする**

## CPU を遊ばせない

- **待ちの間に CPU を遊ばせない**。ディスク・ネットワーク・CPU の待ちを並べられる所は並べる
- **作業者の数は、コア数を基準に決める**。ネットワークの先は、相手ごとに同時に頼む数の上限を設ける
- **1 本のスレッドで 1 つずつ順に回す作りを、既定にしない**

## 画面を止めない

- **画面のスレッドに重い処理を置かない**。CPU を使い切っても、画面は止めない
- **背景で動く処理は、CPU の優先度だけを下げる**。ディスクの優先度は下げない (背景のモードにすると、ほかに何も動いていなくても読みが絞られ、名前の検索が約 3 倍遅くなった)。下げても、ほかに動くものが無ければ CPU を使い切る

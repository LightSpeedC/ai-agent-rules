11/08 に ai-agent-tools から依頼を受けた (#1837)。書き換える先が .md で、同じフォルダに同じ名前の .html (正本) があるとき、Edit・Write を止め、「この .md は html2md の生成物。正本の .html を直して、html2md で作り直す」と返す。正本の .html が無い .md (手で書く Markdown) は止めない。ai-agent-tools で、.md だけを書き換えたあと html2md を流して内容が消える失敗が、今日 2 度起きた。入れたら依頼元へ返信し、生成物の .md への Edit が止まることを確かめてもらう。

**やること**

- [済] 利用者の了承を得て、止める条件と置き場の案を出す
- [済] テストを先に書いて実装し、settings.json のコマンドそのままで試走する
- [済] 依頼元へ返信し、生成物の .md への Edit が止まることの確認を受ける

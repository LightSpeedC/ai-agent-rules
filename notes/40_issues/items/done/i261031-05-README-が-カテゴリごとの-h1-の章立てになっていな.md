品質レビューの指摘。README は `section` が 1 つで、h2 で「ルール」「資料」「課題」を並べている。共通ルールでは、`notes/` のカテゴリ（01_research・10_plan・40_issues・80_quality_review・90_rules）ごとに 1 章の h1 にし、虹色を振る。

**やること**

- [済] 章立てを作り直す（章の数と色相を計算する）
